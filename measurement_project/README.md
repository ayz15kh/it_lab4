# measurement_project

Учебный проект лабораторной работы № 4.

## Запуск
```bash
python main.py
```

## Файлы проекта
- `main.py` — запуск программы и обработка ошибок;
- `utils/reader.py` — чтение чисел из файла;
- `utils/statistics.py` — минимум, максимум и среднее;
- `config.json` — имя файла с данными;
- `data/measurements.txt` — исходные измерения;
- `logs/app.log` — журнал работы программы.

## Виртуальное окружение
```bash
python -m venv .venv
```
